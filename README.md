
# ProyectoJuego

## Descripción
Proyecto desarrollado en Java utilizando Visual Studio Code.

## Archivos principales
- Principal.java: contiene el método principal.
- Funciones.java: contiene los métodos del programa.

## Requisitos
- Java JDK.
- Visual Studio Code.

## Ejecución
Abrir Principal.java y ejecutar el método main.
